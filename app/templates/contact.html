Frequently Asked Questions

When a citizen uploads a photograph, the server runs inference against an Ultralytics YOLOv8 object detection model (or demo synthetic inference fallback). The bounding box, confidence score, and detected category are recorded in the database.

If several citizens photograph the same pothole or crack, generating separate municipal tickets creates administrative gridlock. The system uses haversine DBSCAN to merge nearby reports (≤ 80 meters) into one parent civic issue while preserving all citizen report trails.

The public map endpoint queries only verified, operational issue clusters. Individual user identities, phone numbers, email addresses, and timestamps are stripped by design to ensure compliance with privacy best practices.
